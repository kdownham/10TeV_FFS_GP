# Guinea-PIG Config Files for 10 TeV FFS
---
## Synopsis

Guinea-PIG is a Particle-In-Cell code used for simulating beam-beam effects in particle accelerators. This directory contains the needed input files for running Guinea-PIG to calculate the luminosity 
and other interesting beam-beam parameters for a flat-beam final-focusing system (FFS) designed for the 10 TeV wakefield collider design study [1]. The FFS lattice and particle tracking scripts are 
contained in a different directory [2]. The following sections describe the contents of this repository and commands to run the examples shown here.
